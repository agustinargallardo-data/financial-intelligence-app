# Financial Intelligence App

This project is a personal finance analysis tool designed to track income and expenses,
generate insights, and provide data-driven financial recommendations.

## Project Goals
- Improve personal financial intelligence
- Analyze spending patterns
- Generate automated financial insights
- Serve as a Data Science portfolio project

## Dataset
The dataset contains transaction-level data including:
- Date
- Amount
- Transaction type (income / expense)
- Category
- Description

## Analysis
The exploratory data analysis includes:
- Income vs expenses comparison
- Spending by category
- Top expense categories
- Monthly spending trends
- Rule-based financial recommendations

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Future Improvements
- Expense prediction using machine learning
- Personalized budgeting recommendations
- Interactive dashboard (Streamlit)
